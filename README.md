# Permis Quizz

L'oral du permis B, à voix haute : 91 questions (sécurité routière et premiers secours).

- **Apprentissage** : QCM avec 4 propositions (une ou plusieurs justes), illustrations animées « Comprendre », traduction des mots en russe.
- **Examen blanc** : réponse en vocal (réécouter, puis valider ou recommencer), correction sur le sens, note sur 20.
- **Suivi** : moyenne, courbe de progression, erreurs à retravailler, questions maîtrisées, lexique russe.

Application en ligne : https://fabrice0180-art.github.io/permis-quizz/
